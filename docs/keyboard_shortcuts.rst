.. _keyboard_shortcuts:

#####################################
Keyboard Shortcuts
#####################################

These work in the 3D Viewport while a brush on the *Curve* stroke method is in use with **Activate 3D Curves** on.
They are the same keys as Blender's own paint curves, which they take over while 3D curves are on; turn 3D curves off and
Blender's 2D paint curves have them again.

Left and right mouse buttons are shown for Blender's default *Select with Left* setting, and swap if you select with the right
mouse button. On a Mac, **Cmd** can be used in place of **Ctrl** for adding points, undo and inverted strokes.

.. list-table::
   :widths: 35 65
   :header-rows: 1

   * - Shortcut
     - Action
   * - **Ctrl+Right-click**
     - Add a point (at the nearer end of the active curve, or on the curve), or start a curve
   * - **Ctrl+Right-drag**
     - Add a point and pull out its Bézier handles; on an existing point, pull out its handles; on a handle, drag it
   * - Hold **Ctrl**
     - Preview where Ctrl+right-click would add a point
   * - **Left-click**
     - Select a point; select a curve by its line; deselect everything on empty space
   * - **Shift+Left-click**
     - Add or remove a point from the selection; tick or untick a curve by its line
   * - **A**
     - Select or deselect all the active curve's points
   * - **Right-drag**
     - Move the point or handle under the mouse
   * - **Shift+Right-drag**
     - Move a point, adding it to the selection
   * - **Alt** (while dragging a handle)
     - Break aligned handles, or re-align broken ones
   * - **Ctrl** (while dragging a handle)
     - Scale both handles together
   * - **G** / **R** / **S**
     - Move, rotate or scale the selected points over the surface
   * - **Alt+S**
     - Set the selected points' pressure
   * - **V**
     - Cycle the selected points: Smooth, Sharp, Bézier
   * - **X** / **Delete**
     - Delete the selected points
   * - **Enter**
     - Stroke the brush along the ticked curves, or the active one
   * - **Ctrl+Enter**
     - Stroke inverted
   * - **Ctrl+Z**
     - Undo the last curve edit or stroke
   * - **Ctrl+Shift+Z** / **Ctrl+Y**
     - Redo
